## How to Add an Image to a Post (3 steps)

**Step 1 — Generate**  
Go to bing.com/images/create, paste the prompt, download the image.

**Step 2 — Save to project**  
Put the file in: `/public/images/filename.jpg`  
Create the `images` folder inside `public` if it doesn't exist.

**Step 3 — Add to post frontmatter**  
Open the `.mdx` file and add the `coverImage` line:
```yaml
---
title: "Your Post Title"
date: "2026-06-10"
coverImage: "/images/your-filename.jpg"
---
```

Once all images are added, the cover on each post page will automatically show the real photo with the title and category badge overlaid on top.
